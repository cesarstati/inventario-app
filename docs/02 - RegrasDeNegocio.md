### Regras de Negócio (RN)

- **RN01 - Unicidade do Código**: Cada produto possui um código de barras único.
- **RN02 - Bloqueio de Duplicidade**: Não podem existir dois produtos com o mesmo código.
- **RN03 - Estoque Mínimo**: A quantidade de um produto nunca pode ser negativa.
- **RN04 - Rastreabilidade**: Toda movimentação (entrada ou saída) deve ser registrada no histórico.
- **RN05 - Controle de Acesso**: Somente usuários autorizados (ex: Administrador) podem excluir produtos.
- **RN06 - Auditoria de Inventário**: Todo inventário realizado deve possuir data, hora e um responsável associado.
